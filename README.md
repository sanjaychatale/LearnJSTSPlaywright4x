# Learn JavaScript, TypeScript, and Playwright 4.x

A hands-on learning repository for building JavaScript foundations, with a path toward TypeScript and Playwright 4.x. It contains short notes, examples, and practice exercises organized by topic.

## Learning path

1. [Prompt Engineering](./00_Prompt_Engineering/) — RICE-POT prompts, problem statements, and techniques for reducing hallucinations.
2. [JavaScript Basics](./01_Chapter_JS_Basics/) — introductory scripts and arithmetic.
3. [Keywords and Identifiers](./02_chapter_JS_Keywrods_Identifiers/) — JavaScript engines, declarations, naming rules, and comments.
4. [Literals](./03_chapter_JS_Literals/) — number, string, null, undefined, and other literal examples.
5. [Operators](./04_chapter_JS_Operators/) — assignment, arithmetic, comparison, and logical operators, including comparison edge cases.

Lesson files are numbered to suggest a learning order. Some folders include alternate or copied examples for reference.

## Current scope

The repository currently focuses on JavaScript fundamentals. TypeScript and Playwright 4.x are the intended next steps; lessons for them have not been added yet.

## Running an example

Install [Node.js](https://nodejs.org/), open a terminal in the repository, and run a JavaScript file with `node`, for example:

```sh
node "01_Chapter_JS_Basics/01_HelloWOrld.js"
```

The repository is a work in progress; its current examples focus on JavaScript fundamentals.
